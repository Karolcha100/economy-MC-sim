# Manual data

Hand-made corrections, each row with a note. Review welcome (author task in `AGENTS/todo/author/`).

- `historical-land-borders.csv` — land borders that existed only in earlier years (USSR = RUS, Czechoslovakia = CZE,
  Yugoslavia = SRB, Sudan before 2011). Years are inclusive ("any time during the year"). Imported as
  `history/dyadic/land-borders-historical.csv` (format `pair-ranges`); together with GeoNames (today's borders)
  it seeds `neighbours`. Written 2026-10-14 by Claude Opus 5.5 from general knowledge.
